# Schnaps 0.4.0

- New transparent blueprint icon: an empty bottle with measurement guides.
- A simpler measurement canvas with no activation toolbar, permanent hint banner, or screen dimming.
- Native Zero, Low, Medium, and High tolerance choices in the menu bar and Settings.
- T / Shift-T cycles tolerance presets. Scrolling steps between presets in Find Dimensions, enabled by default and configurable in Settings.
- Tolerance changes immediately update held readings and snapped object bounds.

S switches tools, U switches units, Space pins, Return copies, and Escape exits.

Universal for Apple Silicon and Intel. Requires macOS 14 or later.
