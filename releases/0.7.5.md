## Split Caliper menu-bar icon

The menu-bar icon now reflects whether Schnaps is idle, finding dimensions, measuring an area, or showing design tools. Native template rendering follows the menu bar's appearance, and tooltips name the current state.

## Clearer Find Dimensions labels

Find Dimensions now shows one width × height readout beside the crosshair, including held and pinned measurements. The label stays near the measured point and fits within the display edges.

## Keep Settings visible

Settings stays open when starting measurement and design tools, including shortcut and permission flows. Visible Settings windows remain part of the captured measurement screen.

Universal for Apple Silicon and Intel. Requires macOS 14 or later.
