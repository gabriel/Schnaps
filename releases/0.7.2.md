# Schnaps 0.7.2

- Added native light, dark, and monochrome app icon appearances on macOS 26, with transparent light/dark ICNS icons for earlier macOS versions. The About mark follows the app’s appearance.
- Fixed a crash when hiding the menu-bar icon and when relaunching with an autosaved hidden icon. Preference updates no longer recursively rebuild menus during startup.

Universal for Apple Silicon and Intel. Requires macOS 14 or later.
