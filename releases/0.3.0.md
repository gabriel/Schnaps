# Schnaps 0.3.0

First public release for macOS 14 and later, supporting Apple Silicon and Intel Macs.

- Find Dimensions: live horizontal and vertical distances, gap measurement, and object snapping.
- Measure Area: exact drag selections, moving, corner resizing, and keyboard nudging.
- Pin rectangles or individual dimensions, add guides, and copy dimensions or CSS.
- Native settings with saved units, tolerance, and global shortcuts.
- Bottle-only app icon composed in Apple Icon Composer, including dark and monochrome appearances.
- Signed automatic update delivery through Sparkle 2, with a Check for Updates command.

Screen Recording access enables Find Dimensions. Manual area measurement works without it. Contrast-based detection works best on solid backgrounds.
