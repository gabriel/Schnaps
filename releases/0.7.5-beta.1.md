## Split Caliper menu-bar icon

Schnaps now uses the original Split Caliper design, with four states:

- Open jaws: ready, with no active measurement or visible design tools.
- Measuring span: Find Dimensions.
- Interior rectangle: Measure Area.
- Offset guides: design tools remain visible.

The glyph changes when you start or stop measuring, switch modes with S, hide tools, or dismiss the last mark with Escape. Measurement mode takes priority over existing marks. Tooltips name the state, and native template rendering follows light, dark, and selected menu-bar appearances.

Universal for Apple Silicon and Intel. Requires macOS 14 or later.
